GIT COMMANDS USED IN THIS ASSIGNMENT
====================================

--- Step 1: Local Repository Setup ---

mkdir my-website && cd my-website
  Creates the project folder and moves into it (shell command, not Git).

git init
  Initializes a new, empty Git repository in the current folder (creates the hidden .git directory).

git branch -M main
  Renames the current branch to "main" so the default branch name matches GitHub.

git config user.name "Your Name"
git config user.email "you@example.com"
  Sets the author name and email recorded on every commit in this repository.

--- Step 2: Git Workflow Execution ---

git status
  Shows which files are untracked, modified, or staged for the next commit.

git add index.html about.html
  Stages the two HTML files so they are included in the next commit.

git commit -m "Initial commit: add index.html and about.html"
  Records the staged snapshot as the first commit with a descriptive message.

git add index.html
git commit -m "Update index.html: add welcome message and navigation"
  Stages the modified index.html and records it as the second commit.

git branch feature
  Creates a new branch named "feature" pointing at the current commit.

git checkout feature
  Switches the working directory to the "feature" branch (git switch feature does the same).

git add about.html
git commit -m "Feature: add skills section to about.html"
  Commits the change made on the feature branch; main is not affected.

git checkout main
  Switches back to the main branch.

git merge --no-ff feature -m "Merge branch 'feature' into main"
  Merges the feature branch into main; --no-ff forces a merge commit so the branch is visible in history.

git log --oneline --graph --all
  Displays the full commit history as a compact graph showing all branches and the merge.

git branch
  Lists local branches and marks the current one with *.

--- Step 3: .gitignore Implementation ---

git add .gitignore
git commit -m "Add .gitignore to ignore .log files and temp/ folder"
  Stages and commits the .gitignore file so the ignore rules are tracked.

git status --ignored
  Shows ignored files (e.g., debug.log, temp/) to prove the .gitignore rules work.

--- Step 4: Undo Operation ---

git add contact.html
git commit -m "Add contact.html (to be undone)"
  Makes an additional commit that will be undone.

git revert HEAD --no-edit
  Undoes the last commit by creating a new commit that reverses its changes; history is preserved, so it is safe for shared/pushed branches.

git log --oneline
  Shows the history after the revert, with both the original commit and the "Revert" commit.

(Alternative, not used: git reset --soft HEAD~1 / git reset --hard HEAD~1
  Moves the branch pointer back one commit, removing it from history; --soft keeps changes staged, --hard discards them.)

--- Step 5: GitHub Integration ---

git remote add origin https://github.com/<username>/my-website.git
  Links the local repository to the empty public GitHub repository under the name "origin".

git remote -v
  Verifies the remote URL for fetch and push.

git push -u origin main
  Uploads the main branch and all its commits to GitHub and sets origin/main as the upstream.

git push origin feature
  Pushes the feature branch too, so branch activity is visible on GitHub.

--- Step 6: Documentation ---

git add git_commands.txt
git commit -m "Add git_commands.txt documenting all commands"
git push
  Commits this documentation file and pushes it to GitHub.
